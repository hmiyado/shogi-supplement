# 金無双（囲い）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 3八に自分の玉がある
- 4八に自分の金がある
- 5八に自分の金がある
- 160手以内に成立する

出典: https://www.shougi.jp/kakoi/kinmusou/（公開基本図の玉・金銀配置を照合）
