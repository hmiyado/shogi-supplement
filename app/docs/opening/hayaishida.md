# 早石田（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 20手以内に7五（後手3五）の歩を突き、飛車を7筋（後手3筋）へ振る。角道を止める歩（先手6六・後手4四）は突いていない

その側の指し方を指す戦型なので、条件を満たした側にだけ付く。

出典: shougi.jp/senpou/hayaishida/（「▲7八飛、▲7五歩」「▲7六歩△3四歩のあとに角道を止めず▲7五歩を突く」）
