# 相振り飛車（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 双方の飛車が振り飛車の筋へ定着している

対局単位で決まる戦型なので、成立したら両者に付く。

出典: 双方が振り飛車に振った対局を指す一般的な呼び方
