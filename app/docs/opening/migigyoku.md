# 右玉（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 4八に自分の玉がある
- 5八に自分の金がある
- 24手以内に成立する

出典: shougi.jp/senpou/migigyoku/（本文『居飛車のまま玉将を盤面右側に囲う』。本文に明示座標が無いため、掲載図（table壁のtd/altを筋ヘッダ・段のかな数字と突き合わせて自前で読み取り）から玉4八・金5八を確認して採用。他の右玉形（玉3八型等）は同ページに明示されておらず対象外とした）
