# 左美濃囲い（囲い）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 8八に自分の玉がある
- 7八に自分の銀がある
- 6九に自分の金がある
- 5八に自分の金がある
- 160手以内に成立する

出典: https://www.shougi.jp/kakoi/hidari_mino/（公開基本図の玉・金銀配置を照合）
