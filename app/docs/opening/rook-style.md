# 飛車の筋による大分類

[← 一覧へ戻る](./index.md)

## 判定条件

飛車が同じ筋に10手留まったら、その筋へ定着したとみなす。
一時的に浮いただけの飛車を戦型として拾わないため。
80手を過ぎてからの飛車回りは新たな定着として数えない（中盤の攻めのため）。

| 定着した筋（自分視点） | 表示 |
| --- | --- |
| 2筋（初期の筋のまま） | 居飛車 |
| 5筋 | 中飛車 |
| 6筋 | 四間飛車 |
| 7筋 | 三間飛車 |
| 8筋 | 向かい飛車 |
| それ以外 | 振り飛車（その他） |

名前の付いた筋への最後の定着を優先する。1・3・4・9筋への定着は、
本来の戦型へ移る途中の一時停止であることが多いため。

双方が振り飛車なら相振り飛車、序盤に角交換した振り飛車なら角交換振り飛車が付く。
