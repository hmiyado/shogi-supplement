# 飛車を振った筋による戦型

[← 一覧へ戻る](./index.md)

## 判定条件

飛車をその筋へ振った時点で成立する。24手を過ぎてからの
飛車回りは数えない（序盤に決めた戦型を、中盤の攻めで塗り替えないため）。

| 振った筋（自分視点） | 戦型 |
| --- | --- |
| 3筋 | 袖飛車 |
| 4筋 | 右四間飛車 |
| 5筋 | 中飛車 |
| 6筋 | 四間飛車 |
| 7筋 | 三間飛車 |
| 8筋 | 向かい飛車 |

数えるのは飛車の初期段（自分視点の八段）へ
動かす手だけ。浮き飛車が敵陣寄りの段を横へ動く手（横歩取りの2四飛→3四飛など）は
振ったとみなさない。

最初に振った筋で確定し、その後どこへ回しても変えない。
初期の筋（2筋）のままの対局は判定しない。

双方が振り飛車なら[相振り飛車](./ai-furibisha.md)、序盤に角交換していれば
[角交換振り飛車](./kakukoukan-furibisha.md)が付く（袖飛車は振り飛車に含めない）。
