# 対応している戦型・囲い

アプリが棋譜から判定できる戦型と囲いの一覧。各ページに判定条件と、
テストが実際に通している手順の例を載せている。

このファイルと各ページは `./gradlew generateOpeningDocs` が定義データから生成する。
直接編集しても次の生成で消える。

## 戦型

### 飛車を振った筋で決まるもの

- [飛車を振った筋による戦型](./rook-style.md) — 袖飛車・右四間飛車・中飛車・四間飛車・三間飛車・向かい飛車

### 序盤の出来事で決まるもの

- [相振り飛車](./ai-furibisha.md) — 双方が振り飛車に振っている
- [角交換振り飛車](./kakukoukan-furibisha.md) — 20手以内に角交換が成立している
- [相掛かり](./aigakari.md) — 双方が16手以内に飛車先の歩を5段目（先手2五・後手8五）へ伸ばし、その手数差が8手以内
- [角換わり](./kakugawari.md) — 20手以内に角交換が成立し、その時点で双方の飛車がまだ初期の筋にいる
- [一手損角換わり](./itteson-kakugawari.md) — 角換わりが成立している
- [横歩取り](./yokofudori.md) — 相掛かりが成立している
- [筋違い角](./sujichigai-kaku.md) — 角交換から10手以内に、自分の角を筋違いのマス（先手4五・後手6五）へ打つ
- [早石田](./hayaishida.md) — 20手以内に7五（後手3五）の歩を突き、飛車を7筋（後手3筋）へ振る。角道を止める歩（先手6六・後手4四）は突いていない
- [ひねり飛車](./hineribisha.md) — 相掛かりが成立している
- [地下鉄飛車](./chikatetsu-bisha.md) — 自陣の最下段へ引いた飛車を、その段のまま60手以内に端筋（先手9筋・後手1筋）へ回す

- [早繰り銀](./hayakurigin.md) — 4六銀

## 画面に出す代表の戦型

1局に複数の戦型が成立する（角換わりで棒銀に出るなど）。対局情報では成立した
ものをすべて並べ、棋譜一覧の絞り込みもそのどれでも引ける。カードなど1つしか
置けない場所では次の順で先にあるものを選ぶ。

1. 横歩取り
2. ひねり飛車
3. 一手損角換わり
4. 角換わり
5. 相掛かり
6. 矢倉
7. 雁木
8. 筋違い角
9. 早石田
10. 石田流
11. ツノ銀中飛車
12. 中飛車
13. 四間飛車
14. 三間飛車
15. 向かい飛車
16. 右四間飛車
17. 袖飛車
18. 地下鉄飛車
19. 雀刺し
20. 右玉
21. 相振り飛車
22. 角交換振り飛車

この並びに無い戦型（攻めの形など）は代表にはせず、並記と絞り込みにだけ出る。
