# 本美濃囲い（囲い）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 2八に自分の玉がある
- 3八に自分の銀がある
- 5八に自分の金がある
- 4九に自分の金がある
- 160手以内に成立する

成立の判定は片美濃囲いと独立している（片美濃囲いを経由していなくても、
この形になれば成立する）。両方成立したときの表示だけこちらを優先する。

出典: ja.wikipedia.org/wiki/美濃囲い（玉2八・銀3八・左金5八・右金は初期位置4九のまま）
