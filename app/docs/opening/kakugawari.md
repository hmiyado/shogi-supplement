# 角換わり（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 20手以内に角交換が成立し、その時点で双方の飛車がまだ初期の筋にいる
- 角交換が成立した時点から20手以内にどちらも振り飛車へ定着しない
- 角交換から10手以内に角を打たない（筋違い角を除く）
- 同じ対局で角交換振り飛車が成立していない

対局単位で決まる戦型なので、成立したら両者に付く。

出典: ja.wikipedia.org/wiki/角換わり（「序盤で角を交換した後に駒組みを進める相居飛車の戦法」）
