# 振り飛車穴熊（囲い）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 1九に自分の玉がある
- 2八に自分の銀がある
- 3九に自分の金がある
- 160手以内に成立する

出典: ja.wikipedia.org/wiki/穴熊囲い（居飛車穴熊と筋対称の振り飛車側の形）
