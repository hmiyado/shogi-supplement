# 嬉野流（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 5七に自分の銀がある
- 5六に自分の歩がある
- 7七に自分の歩がある
- 24手以内に成立する
- 自分の最初の着手が6八銀（後手4二銀）である
- その形が成立するまでに角交換が起きていない

出典: https://store.shogi.or.jp/view/item/000000002588 （自分の初手6八銀、角道を開けず5六歩・5七銀。7九角を保留する新嬉野流も含む）
