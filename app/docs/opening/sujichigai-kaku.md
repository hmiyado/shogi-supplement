# 筋違い角（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 角交換から10手以内に、自分の角を筋違いのマス（先手4五・後手6五）へ打つ

その側の指し方を指す戦型なので、条件を満たした側にだけ付く。

出典: shougi.jp/senpou/sujichigaikaku/（「▲7六歩△3四歩▲2二角成△同銀▲4五角」）
