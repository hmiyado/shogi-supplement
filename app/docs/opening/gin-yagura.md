# 銀矢倉（囲い）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 8八に自分の玉がある
- 7七に自分の銀がある
- 6七に自分の銀がある
- 7八に自分の金がある
- 160手以内に成立する

成立の判定はカニ囲いと独立している（カニ囲いを経由していなくても、
この形になれば成立する）。両方成立したときの表示だけこちらを優先する。

出典: https://www.shougi.jp/kakoi/gin_yagura/（公開基本図の玉・金銀配置を照合）
