# ツノ銀中飛車（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 4七に自分の銀がある
- 6七に自分の銀がある
- 30手以内に成立する

出典: shougi.jp/senpou/furibisya/tsunogin_nakabisya.html（本文『2つの銀がツノのように見えることからこの名前がついた』。掲載図で左銀6七・右銀4七を確認。飛車は中飛車へ向かう途中の一時的な配置(図では5九のまま)で、振った筋は別途『中飛車』として判定するため、本タグでは銀のツノ形のみを必須とした）
