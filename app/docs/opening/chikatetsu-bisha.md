# 地下鉄飛車（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 自陣の最下段へ引いた飛車を、その段のまま60手以内に端筋（先手9筋・後手1筋）へ回す

その側の指し方を指す戦型なので、条件を満たした側にだけ付く。

出典: ja.wikipedia.org/wiki/地下鉄飛車（「飛車を1段目に引いた後、飛車を転換して指す」「9筋に飛車を転換すると地下鉄飛車となる」）
