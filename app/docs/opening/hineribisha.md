# ひねり飛車（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 相掛かりが成立している
- 飛車先の歩を交換したあと、40手以内にその飛車を3六（後手7四）へ寄せる

その側の指し方を指す戦型なので、条件を満たした側にだけ付く。

出典: shougi.jp/senpou/hineribisya/（「相掛かり戦法の出だしから飛車を左翼に転換して戦う戦法」「▲３六飛まで」）
