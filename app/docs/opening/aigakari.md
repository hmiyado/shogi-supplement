# 相掛かり（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 双方が16手以内に飛車先の歩を5段目（先手2五・後手8五）へ伸ばし、その手数差が8手以内
- 伸ばし切った時点で双方の飛車がまだ初期の筋にいる
- 24手以内に飛車先の歩交換がある（先手2四・後手8六で飛車が歩を取る）
- 24手以内に角交換が成立していない
- 飛車先を伸ばし切った時点から20手以内にどちらも飛車を振らない

対局単位で決まる戦型なので、成立したら両者に付く。

出典: ja.wikipedia.org/wiki/相掛かり（「飛車先の歩を伸ばし合い」「角交換は行わない」「飛車先の歩を交換してから飛車を引く」）
