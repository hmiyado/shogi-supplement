# エルモ囲い（囲い）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 7八に自分の玉がある
- 6八に自分の銀がある
- 7九に自分の金がある
- 160手以内に成立する

出典: ja.wikipedia.org/wiki/エルモ囲い（7八玉・6八銀・7九金型）
