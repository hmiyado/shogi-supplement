# 角交換振り飛車（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

駒の配置ではなく、序盤に何が起きたかで決まる。次をすべて満たすと成立する。

- 20手以内に角交換が成立している
- 自分の飛車が振り飛車の筋へ定着している

その側の指し方を指す戦型なので、条件を満たした側にだけ付く。

出典: ja.wikipedia.org/wiki/角交換振り飛車（序盤に角を交換してから振る指し方）
