# 早繰り銀（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 4六に自分の銀がある
- 40手以内に成立する

出典: shougi.jp/senpou/hayagurigin/（本文『主に角換わり、後手番一手損角換わり、相掛かりにおいて、右銀を3七〜4六に活用する作戦の総称。▲4六銀-▲3五歩と攻める筋がある』。3七はまだ途中形（一間飛車のような通過点）なので、本文が名指しする到達点▲4六銀を厳密形として採用した）
