# ゴキゲン中飛車（戦型）

[← 一覧へ戻る](./index.md)

## 判定条件

座標は自分視点（先手の8八＝後手の2二）。次をすべて満たした時点で成立し、
以後その対局の記録として残る。

- 5八に自分の飛がある
- 5五に自分の歩がある
- 7六に自分の歩がある
- 8八に自分の角がある
- 6六が空いている
- 24手以内に成立する
- その形が成立するまでに角交換が起きていない
- 成立までに角道を止める歩（先手6六・後手4四）を突いていない

出典: https://store.shogi.or.jp/view/item/000000002584 （角道を止めない中飛車。5五歩型の基本形を対象とし、角交換前に成立したものを記録する）
