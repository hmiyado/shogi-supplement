# release-x-post（リリース告知のXポスト）

## フォーマット

```
【アップデート】将棋サプリ <バージョン> を公開しました🎉

・<機能名>：<ユーザーにとって何ができるか>
・<機能名>：<ユーザーにとって何ができるか>

https://apps.apple.com/jp/app/%E5%B0%86%E6%A3%8B%E3%82%B5%E3%83%97%E3%83%AA/id6792424283
```

- 見出しは1行。絵文字は見出し末尾の🎉だけ
- 箇条書きは `・` で始め、`機能名：効果` の形。3項目までに絞る
- 最初のリリースなど「アップデート」でない告知は見出しを変える

## 作り方

1. `docs/release-notes.html` の該当バージョンの項目を正とする。
   リリースノートに無いことは書かない
2. 項目が3つを超えるときは、ユーザーの利得が大きいものから選ぶ。
   「安定性の改善」は他に載せる項目があるなら省く
3. 文言は `docs/wording.md` に従う。表にある語はそのまま使う
4. 文字数はURLを除いて日本語140字以内（Xは日本語を2文字として数える。URLは長さに関わらず23文字）

## 書かないもの

- 誇張・ゲーミフィケーション語彙（`DESIGN.md`「根拠で語る学習」）。
  「劇的」「圧倒的」「最強」「もう〜しない」の類は使わない
- 実装が保証しない範囲。リリースノートより広い約束をしない
  （例: 引き継ぎで戻るのはアカウントと棋譜。解析結果まで戻ると書かない）
- 文字の「▶」（iOSで絵文字レンダリングされる）
