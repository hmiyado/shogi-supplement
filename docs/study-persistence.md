# 検討分岐

検討は原文棋譜と分けて保存する。分岐の追加・削除は端末へ自動保存する。保存失敗時は編集を画面に保持して再試行を表示し、未保存のまま棋譜を離れる場合は確認を出す。

## 識別と復元

- モバイルでは元棋譜のレコード、Webでは元棋譜原文のSHA-256で保存先を特定する。
- KIFの各手・終局手の消費時間と累計消費時間を保持する。
- KIFの親子関係と兄弟順序を維持する。同じ指し手で始まる分岐も別ノードとして選択・編集・削除できる。表示中はノードIDを使い、保存時は親子関係を再構築する。ノードIDを異なる棋譜や読み込みセッションの間で共有しない。
- 本譜の手順と終局は変更しない。検討開始点より前の棋譜、他の開始点の検討も保持する。
- アプリ内でのメモ・しおりの編集や、しおりからの移動は提供しない。取り込んだKIFに含まれるコメント・しおりはデータとして保持し、分岐保存・KIF出力で失わない。
- 比較更新で、別画面・別タブによる保存の上書きを拒否する。競合した編集は画面に保持する。

## Webの復元棋譜

マイページで復元した棋譜も検討できる。初回はクラウドの検討をブラウザ内へ取り込む。同じ棋譜のローカル保存がある場合はその続きから開き、クラウドの内容で上書きしない。検討の保存先は画面に明示する。Webのこの操作ではクラウドを更新しない。

## 削除

- 検討分岐の削除は選択した枝とその子孫のメモ・しおりを対象とする。本譜と兄弟分岐は残す。削除確認の後、端末内の保存済み分岐からも削除する。
- 元棋譜を端末から削除すると対応する検討も削除する。Webでは棋譜と検討を一つの取引で削除し、他タブの編集があれば削除を拒否する。削除済みの検討を古いタブの保存で復活させない。
- クラウド側の削除と端末側の削除は独立している。Webの復元棋譜に対する編集・保存はブラウザ内のコピーだけに作用する。
- 旧版が使うデータと新版の更新先は分離する。旧版は旧データを使い、新版は新データを優先して旧データも読める。Supabase変更の本番適用は別途行う。

## 検討画面の操作配置

評価値には先手/後手の視点と分岐元を添える。評価値・候補手・分岐の順で表示し、削除は評価行の「⋯」（検討の操作）から行う。手動保存と未保存の印は表示しない。評価行と候補手行は解析状態によらず固定高さとし、保存失敗時だけ再試行付きのメッセージを重ねて表示する。削除は確認を挟み、本譜は削除できない。

## 保存済み解析の初期表示

検討開始時に元棋譜の本譜と局面評価を対応づけ、開始局面と本譜の各手へ評価を設定する。表示中の先後・評価表示設定を反映し、保存済みの最善手・次善手があれば候補にも使う。保存済み評価がある本譜は自動で再解析しない。評価が欠けている局面や新たに作った分岐は通常どおり解析する。

評価は手数だけで別分岐へ流用せず、本譜の経路で照合する。途中からの検討は本譜上の手数へ対応づける。評価を表示用の木へ設定しても検討文書の未保存変更には含めない。

検討の青いナビ行の左右矢印でも、表示中の本譜・選択中の分岐を一手ずつ前後へ移動できる。開始局面では戻る矢印、表示手順の末尾では進む矢印を無効にする。局面移動は棋譜チップの選択と同じ処理を使う。
