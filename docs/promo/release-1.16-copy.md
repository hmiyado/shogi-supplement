# 将棋サプリ 1.16 告知素材

## リリースノート

- 検討の手順や変化を見やすくし、分岐を横スクロールで表示するようになりました。
- 金無双・左美濃囲い・カニ囲い・片矢倉・銀矢倉・ミレニアム・銀冠穴熊・天守閣美濃・ゴキゲン中飛車・嬉野流の10種類を、囲い・戦型の判定に追加しました。
- 詰みを確認できた場合だけ「N手詰」と表示し、未確認の勝ち・負けと区別するようになりました。
