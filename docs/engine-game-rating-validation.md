# Aobaの棋譜解析・棋力推定への影響

2026-09-28。2026-09-16に取得した同一300局のHáo/Aoba解析を再集計し、5-foldの学習と評価を再実行した。新規エンジン探索・本番変更は行っていない。「棋力推定は未検証」という説明を訂正する。既に予備検証はあり、今回その再現と棋譜解析への影響を確認した。

## 条件と検証

9.40＋Háo（FV_SCALE20）と9.80＋Aoba（FV_SCALE40）、400,000 nodes、Threads1、Hash128MiB、MultiPV2、定跡なし。同じ300局・600人を使い、プレイヤーが学習側と評価側に跨がない5分割。各回240局で学習、60局で評価。現在の6特徴量と線形回帰を固定する。

現行のStrengthEstimator.kt、FeatureExtractorV2.kt、Blunder.ktは、実験時のmanifestに記録されたSHA-256と一致。両エンジン合わせて1,200側分の特徴量・凍結式予測を現行Python実装で再計算し保存値と一致。600解析ファイルの内容ハッシュと以前のPV合法性検証キャッシュも照合済み（54,702局面・1,160,491 PV手）。PVを全手指し直す検証の再実行ではない。

## 棋譜解析

現行の悪手定義v1.1（最善手一致除外・詰み見逃し・頓死・500cpスイング）を27,051着手に適用した。

| 指標 | 結果 |
| --- | ---: |
| Háoの悪手 | 1,672手 |
| Aobaの悪手 | 1,583手 |
| 両方で悪手 | 1,207手 |
| Háoだけ悪手 | 465手 |
| Aobaだけ悪手 | 376手 |
| 判定一致率 | 96.89% |
| Cohenのκ | 0.725 |
| 悪手判定が1手以上変わる棋譜 | 244 / 300局 |
| 最善手が変わる着手前局面 | 10,576 / 27,051局面 |
| 勝率換算損失の絶対変化・平均 | 2.41ポイント |
| 同・95パーセンタイル | 7.65ポイント |

平均の勝率換算損失はHáo3.37ポイント、Aoba3.51ポイント。これはシグモイドによる換算値で、実勝率の校正検証ではない。悪手数の減少や最善手の変更は精度改善の証明ではない。どちらが正しいかを判定する独立した正解ラベル／深い探索による裁定は今回含めていない。カテゴリ分類と教材難易度の再校正も対象外。

## 棋力推定

| 構成 | 未学習側MAE | RMSE |
| --- | ---: | ---: |
| Háoで再学習 | 181.45 | 230.90 |
| AobaにHáoの各fold学習係数を流用 | 177.34 | 226.18 |
| Aobaで再学習 | 177.97 | 226.68 |

「係数流用」は各foldの学習側で作ったHáo係数であり、本番の凍結係数そのものではない。Aoba再学習−Háo再学習のMAE差は−3.49、局単位・先手帯内ペアbootstrap 10,000回の95%区間は[−8.12, +1.13]。Aoba再学習−Háo係数流用は+0.63、区間[−0.50, +1.76]。改善も悪化も確定しない。非劣性マージンを事前設定していないため非劣性試験の合格とは呼ばない。

区間は固定OOF予測からの近似で、再標本化ごとに再学習していない。特徴量の過去の選択には同じ元コーパスを使っており完全な外部検証ではない。1人1局のため複数局集約・偏差値基準・誤差幅は未検証。候補係数のdeployment_readyはfalseのまま。

## 判断

Aobaを棋譜解析・棋力推定に使用できないという結果ではない。一方、既存の悪手レポートは多くの棋譜で変わり、棋力推定の改善は実証できない。全面置換の品質承認には、判定不一致局面の裁定と、独立データによる複数局集約・校正の確認が残る。

再現: `.venv/bin/python tools/compare_game_engine_outputs.py /path/to/aoba-retraining --output docs/verification/engine-game-comparison.json`。学習再実行は `.venv/bin/python /path/to/aoba-retraining/evaluate.py`。元データと学習スクリプトはgit管理外の既存実験ディレクトリにある。
