# 定跡手順と局面ラベル

v1.15 / #104。画面構成・操作は承認済みモックを参照し、実装の外観は既存画面・DESIGN.mdに合わせる。

## 保存と照合

- 定跡手順・局面ラベルは端末とサーバーへ保存する。
- 局面全体ラベルは盤面の駒配置（先後・成を含む）と双方の持駒が一致する局面へ共通に適用する。
- 先手の形・後手の形ラベルは、指定側の全盤上駒配置（成を含む）とその側の持駒を照合し、相手側は無視する。既存の全体ラベルのキー・保存形式を維持し、片側キーにBLACK:/WHITE:を付けて区別する。
- 照合では手番と手数を無視する。棋譜の途中の局面も対象にする。
- 棋譜一覧では局面ラベルで絞り込む。「一致する局面」の補助行は表示しない。

## 画面と操作

- 一覧は定跡名と、初期局面・全分岐に含まれるラベルを重複なしで表示するカード。カード全体から開き、下部の「定跡を追加する」で作成する。
- 盤面下は「定跡」「局面ラベル」「検討」。検討にはレポート画面と共通の操作・手順・候補を使う。
- 画面タイトルは「定跡」。ホームの入口は現状維持とし、下タブ化は別Issue #106で扱う。
- 盤の外側の追加横余白を設けない。定跡画面と初期盤面編集に反転操作を置き、持駒も上下を入れ替える。
- 操作メニューから初期盤面を編集する。ドラッグで盤・持駒・駒箱を移動でき、ドラッグ自体では先後・成を変えない。空きマス以外や領域外へのドロップでは移動しない。
- 持駒は通常の盤面と同じ位置（後手が上、先手が下）。駒箱はその下。
- 盤上の駒をタップすると選択し、先手不成→先手成→後手不成→後手成の順に切り替える。金・玉は先後だけ。
- 選択した駒は空きマス・持駒領域・駒箱領域のタップで移動する。持駒と駒箱では不成に戻す。玉は持駒には入れない。
- 駒箱は実際に盤・持駒から取り除いた駒だけを表示する。
- 「平手に戻す」は小さいテキスト操作。手順を消す注意は変更の適用時にダイアログで出す。

## 実装と検証

- Android/iOSのホームから定跡一覧へ入る。検討は既存のStudyController・StudyPanel・盤面・タブ表示を共用する。
- レポートの「操作」から局面ラベルを編集し、表示中の手順を定跡として登録できる。
- 本譜と保存した検討分岐の局面をラベルの照合対象にする。絞り込みの保存条件にも局面ラベルを含める。
- 端末はアカウント別のSQLite保存と送信キュー。DB移行は25.sqm。送信応答が失われても同じトークンと内容で再送する。
- サーバーはrepertoire_entriesとput_repertoire_entry RPC。定跡名・手順・局面ラベルは既存の引き継ぎ鍵で暗号化し、認証した本人にだけアクセスを許可する。
- 一覧や棋譜一覧を開いた時、レポートの操作を開いた時、編集保存時に同期する。サーバーとの競合時は端末の未送信編集を保持する。競合の自動マージは行わない。
- 既存レポートの検討パネル5枚は現行コードより古い基準画像だったため、現行表示へ更新した。
- 共通ロジック、SQLite保存・再起動・送信中編集・通信断後の再送、暗号化HTTP往復、局面ラベル・保存フィルタ、UI操作をテストした。
- Androidの新規画面・盤面・レポートのVRT、iOS simulator向け共通UIとWeb/Wasmのコンパイルを確認した。
- 本番マイグレーション適用、実機での操作、実サーバーへの保存・復元は未実施。コードとローカル環境の検証を、本番反映済みとは扱わない。

## ラベルの追加・削除と一覧表示

- 局面ラベルタブの上部に、初期局面と全分岐に付いたラベルを表示する。下部は現在の局面を対象とする。
- 追加は「局面ラベルを付ける」から対象とラベル名を入力する。「編集」は設けない。
- 1局面の対象（局面全体・先手の形・後手の形）ごとに1件、最大3件。登録済みの対象には追加できず、削除後に追加する。
- 各ラベルの×で確認ダイアログを表示し、確定時だけ削除する。同じ局面・形の別棋譜からも外れることを確認文に示す。
- 削除は内容が空のラベル行として同期し、古いサーバー行からの復活を防ぐ。確認中に更新された行は上書きせず再操作を求める。
- 旧形式の複数ラベルは自動削除しない。表示・個別削除を可能にし、空になってから1件追加できる。
- ホームと棋譜一覧の共通カードにラベルを表示する。ホームでもアカウント単位の端末保存・同期内容を読み込む。

### ラベルから局面へ移動

ラベル名を選ぶと、初期局面から主順・分岐を深さ優先で探索し、最初に一致する局面へ移動する。×は16dpの副文字色とし、40dpの操作領域を維持する。削除確定だけを朱色にする。定跡画面上部の操作メニューは廃止し、定跡タブに「初期局面を作成」を置く。絞り込みには保存済み全ラベルを表示し、該当棋譜がないものは選択不可にする（選択済み条件は解除できる）。
