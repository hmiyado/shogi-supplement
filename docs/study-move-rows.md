# 検討の手順表示（#110）

2026-10-16、[モック](mockups/study-move-rows.html)の修正案を承認後に実装。

手順を1手1行で表示する。左列は棋譜初手からの絶対手数（開始局面の手数＋検討内の深さ＋1）。前後ナビも同じ手数で表示する。

兄弟分岐は同じ行に並べ、横スクロールで選択する。候補には採番しない。同じ指し手の兄弟もノードIDで別々に選択可能。選択した候補の局面へ移動し、その分岐の後続手順と評価値を表示する。保存・復元・削除は既存の検討木の処理を利用する。

分岐候補の幅は指し手8em・評価値7文字相当・間隔12dp・左右余白各16dp。評価未取得も同じ領域を確保し、行高56dpを変えない。分岐のない行は残り幅を使い、評価値を右寄せする。選択済み分岐は淡い注目色、現在手は注目色、未来手は淡色。評価値の視点は従来どおり候補手付近に表示する。

現在手の行へ縦スクロールし、選択した兄弟候補を横の表示範囲に入れる。レポート・ドリル・定跡の共通パネルに適用する。

検証は分岐選択と遅延評価の共通テスト、絶対手数・評価値更新前後の位置固定・横スクロール選択・長い手順の現在行表示のUIテスト、明暗を含む関連画面の画像比較で行う。
