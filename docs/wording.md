# 文言表（ユーザー向け文言の用語統一）

対象は**ユーザーの目に触れる文言すべて**（アプリ内UI・ストア文言・規約/プラポリ・
ヘルプ・お知らせ）。コード内部の識別子・コメント・設計資料は対象外
（内部の推定はレート軸のままでよい）。

新しい文言を書くとき・レビューするときは、この表に反する語をフラグする。
表に無い揺れを見つけたら、決めてから行を追加する。

## 表記・スタイル

- ◎noteに「訓練で消せる」等の断定的な付記はしない（2026-07-19 #17）
- WASMの実体（ダウンロード・キャッシュされるエンジン等のファイル群）は「WASMバイナリ」と
  呼ぶ。「資産」「アセット」は使わない（コード内コメントも同様。英語識別子・URLパスの
  asset/kento-assets は既存のまま）（2026-08-09）

## はじめに（同意オンボーディング・iOS）

アカウントを作るか作らないかの二者択一。**それぞれで何ができるかだけを並べ、
選ばなかった側で何ができないかは書かない**。

アカウントの作成と棋譜の保存は別物として扱う。アカウントはサーバー解析に必要で、
棋譜の保存（研究・改善への提供、引き継ぎの前提）はそのうえで切り替えられる。
オンボーディングでアカウントを作ると保存も既定でONになり、あとから設定で外せる。
引き継ぎは保存が前提のため、説明でも「保存すると引き継げる」と依存関係を明示する。

| 用途 | 文言 |
|---|---|
| 見出し | はじめに |
| 導入 | 将棋サプリは棋譜を解析して棋力を推定し、棋力帯相応の悪手を次の一手問題として出題します。 |
| 選択肢1 | 匿名のアカウントを作成して始める |
| 選択肢1の説明 | ベータ版では1日30局まで早く解析できます。30局を超えると解析が遅くなります／サーバーに棋譜を保存すると、機種変更のときに棋譜を引き継げます／名前・メールアドレスの入力は必要ありません／サーバーに保存した棋譜と結果は匿名で研究・改善（アプリ改善・棋力推定の較正）に利用されます |
| 選択肢2 | アカウントを作成せずに始める |
| 選択肢2の説明 | 解析は端末内で行います。棋譜はサーバーに送信されません |
| 開始ボタン | 規約に同意して始める |

ボタンの「同意」は**利用規約・プライバシーポリシーへの同意**を指す（どちらの選択肢でも共通）。
研究利用への同意はアカウントを作る側の説明に含まれる。規約へのリンクはボタンの直上に置く
（選択肢と同じ領域に置くと、直前の選択肢に属する説明に見えるため）。

## アカウント画面（設定→アカウント）

アカウントの作成・削除が主役。棋譜の保存はその下の切り替えとして分ける
（アカウント＝サーバー解析に必要、棋譜の保存＝研究・改善への提供と引き継ぎの前提）。
未作成時の説明は「はじめに」と同じ項目を参照し、画面ごとに書き分けない。

| 用途 | 文言 |
|---|---|
| 画面名 | アカウント |
| 未作成時の説明 | 匿名のアカウントを作成すると、サーバーでの解析が使えます。名前・メールアドレスの入力は必要ありません。 |
| 作成ボタン | アカウントを作成 |
| 作成済みの表示 | 作成済み |
| 保存件数 | サーバーに保存した棋譜 N局 |
| 引き継ぎの補足 | サーバーに保存した棋譜は、引き継ぎコードで別の端末へ移せます |
| 保存の切り替え | 棋譜をサーバーに保存する |
| 保存の切り替えの説明 | 解析した棋譜を保存します。研究・改善に匿名で利用され、引き継ぎのもとになります |
| 削除ボタン | アカウントを削除 |
| 削除確認の見出し | アカウントを削除しますか？ |

「棋譜提供」「データ提供」は使わない（アカウントと保存が同じものに見えるため）。

## 棋譜の削除（棋譜一覧・レポート画面）

| 用途 | 文言 |
|---|---|
| アイコンの説明 | 棋譜を削除 |
| 確認見出し | この棋譜を削除しますか？ |
| 確認本文（端末のみ） | 解析結果も含め、端末から削除されます。この操作は取り消せません。 |
| 確認本文（サーバーも含む） | 解析結果も含め、端末・サーバーから削除されます。この操作は取り消せません。 |
| サーバー削除チェックボックス | サーバーに保存した棋譜も削除する |

確認ダイアログの本文には、解析結果も消えることと、取り消せないことの2点を必ず含める。

## アカウント作成（棋譜の追加時・設定画面）

アカウントを作らなくても端末内での解析は使える。**できないことは並べず、できることだけを書く**。

| 用途 | 文言 |
|---|---|
| 確認ダイアログ見出し | アカウントの作成 |
| 確認ダイアログ本文 | 棋譜を解析すると匿名アカウントを作成します。作らなくても、端末内での解析は使えます。 |
| 作る（確定） | 続ける |
| 作らない | 作らずに解析 |
| 設定行（作らずに使っている端末にだけ出す） | アカウントを作成する |
| 設定行の補足 | サーバーでの解析・引き継ぎが使えるようになります |

## 引き継ぎコード表示（設定画面）

パスワードと同様の扱い。既定は伏字（マスク）表示で、コピーはマスク中でも常時可能。
生の値はユーザーの明示操作（表示切替アイコン）でのみ見せる。

| 用途 | 文言 |
|---|---|
| 表示アイコンの説明（マスク中→タップで表示） | コードを表示 |
| 表示アイコンの説明（表示中→タップで隠す） | コードを隠す |

### 作り直し

漏れたコードを無効にする手段。**新しいコードで何ができるか**を先に書き、失うものは
「いまのコードは使えなくなります」の一文に留める。復号鍵は据え置きのため、
保存済みの棋譜は引き続き引き継げる（この安心材料を必ず併記する）。

| 用途 | 文言 |
|---|---|
| ボタン | コードを作り直す |
| 確認見出し | コードを作り直しますか？ |
| 確認本文 | 新しいコードを発行し、いまのコードは使えなくなります。サーバーに保存した棋譜はそのまま引き継げます。 |
| 確定 | 作り直す |
| 失敗 | 作り直しに失敗しました。時間をおいてお試しください |

「再生成」は使わない（内部の実装用語）。

## 棋譜復元（引き継ぎコード復元後の棋譜ダウンロード）

失敗の文言は引き継ぎコード入力と**同じにしない**（見出しを共有しているため、同じ文言だと
コードが通らなかったのか棋譜を取れなかったのかを利用者が区別できない）。

引き継ぎコード入力の成功後に遷移する画面。見出しは引き継ぎコード入力の成功メッセージ
（「アカウントを切り替えました」）を再利用し、ここで別の見出しは持たない。

| 用途 | 文言 |
|---|---|
| 件数確認中 | サーバー上の棋譜を確認しています |
| 件数表示（N局） | サーバーに N 局の棋譜があります。 |
| 件数表示（0局） | サーバーに保存された棋譜はありません。 |
| 復元開始ボタン | 棋譜を復元する |
| 進捗（n/N局） | 復元中... n / N 局 |
| 完了（全件成功） | N 局を復元しました。 |
| 完了（一部失敗） | N 局を復元しました（M 局は失敗）。 |
| エラー: ログイン状態不明 | ログイン状態を確認できませんでした。設定からやり直してください。 |
| エラー: 復元用データ無し | 復元用のデータが見つかりませんでした。もう一度お試しください。 |
| エラー: 通信断・その他 | 通信に失敗しました。しばらくしてから再度お試しください。 |
| 再試行ボタン | 再試行 |

ホームへ戻るボタンは既存の `DRILL_GO_HOME`（「ホームへ」）をそのまま再利用する（新規文言を
増やさない）。文言の実体は `AppStrings`（AppStrings.kt「37. 棋譜復元」節）に一元化する。

## マイページ（Web版・引き継ぎコードでログインして棋譜一覧を見る）

ログイン導線は設定画面の「引き継ぎコードを入力」（引き継ぎコード入力節）と同じ文言を使う
（役割が同じダイアログを開くボタンのため、新しい表現を作らない）。

| 用途 | 文言 |
|---|---|
| ログイン前の説明文 | アプリの設定画面で表示した引き継ぎコードを入力すると、自分の棋譜一覧を見られます。 |
| ログインボタン | 引き継ぎコードを入力 |
| エラー: 端末シークレット未生成 | 棋譜を復元できませんでした。もう一度ログインし直してください。 |
| エラー: 該当棋譜なし | この棋譜が見つかりませんでした。削除された可能性があります。 |
| エラー: 通信断・その他 | 通信に失敗しました。しばらくしてから再度お試しください。 |
| エラー: ログアウト失敗 | ログアウトに失敗しました。もう一度お試しください。 |
| ログアウトボタン | ログアウト |
| 一覧へ戻るボタン（エラー画面。一覧から遷移した場合のみ表示） | 一覧へ戻る |

「ログアウト」は既存の「アカウントを削除」（アカウント削除節参照）とは別物: このブラウザでの
セッションと復号鍵を消すだけで、アカウント自体・サーバー上の棋譜は残る（共有ブラウザでの
利用を想定した機能のため、モバイル版には無い概念）。

文言の実体は `AppStrings`（AppStrings.kt「39. マイページ」節）に一元化する。
