# 文言表（ユーザー向け文言の用語統一）

対象は**ユーザーの目に触れる文言すべて**（アプリ内UI・ストア文言・規約/プラポリ・
ヘルプ・お知らせ）。コード内部の識別子・コメント・設計資料は対象外
（内部の推定はレート軸のままでよい）。

新しい文言を書くとき・レビューするときは、この表に反する語をフラグする。
表に無い揺れを見つけたら、決めてから行を追加する。

## 用語

| 使う | 使わない | 理由・補足 | 決定 |
|---|---|---|---|
| 棋力帯 | レート帯、帯（単独） | ユーザー向けには「レート」より「棋力」。「帯」単独は初見で通じない | 2026-07-19 #8 / 2026-07-28 |
| 相手の最善応手列 | 咎め | 将棋用語「咎める」は初級者に通じない | 2026-07-19 #13 |
| 答えを見る | 降参（答えを見る） | 「降参」の負の印象を避ける | 2026-07-19 #17 |
| 偏差値（推定棋力の表示） | レート値の生表示 | 表示は偏差値に統一（StrengthNorm）。内部推定はレート軸のまま | 2026-07-19 |
| 推定棋力 | 棋力、レーティング（推定値の意味で） | 申告棋力と区別するため「推定」を明示する | 2026-07-28 |
| 悪手率: X%(m/n) | 見つかった悪手（件数見出し）、判定別内訳チップ（「見送りN件」等） | 件数の生表示や判定別内訳は意味が伝わりにくいため率で示す（m=悪手数/n=自分の手数） | 2026-08-01 |
| 一致率（最善・次善）: Y%(l/n) | エンジン一致率（最善/次善）: あなたY% | 悪手率と同格の表示・同じ分母nで並べる（l=top2一致手数） | 2026-08-01 |
| 悪手一覧を見る | すべて見る | ホーム画面の「すべて見る」（棋譜一覧への導線）と紛れるため、何の一覧かを明示する | 2026-08-01 |
| サマリーに戻る | 戻る（単独） | レポート画面トップバーの「戻る」（画面自体を閉じる）と混同しないよう戻り先を明示する | 2026-08-01 |
| 検索（絞り込み条件の適用ボタン） | 適用、絞り込む | 棋譜一覧の絞り込みボトムシートで条件を確定するボタンに使う語をここに統一 | 2026-08-01 |
| 棋譜を検討する（Webの機能名・CTA） | デモ、お試し、体験版 | 内部位置づけ（アプリの検討機能をブラウザ内WASMで再現したもの）はユーザー向け文言に出さない。ひとつの機能として見せる | 2026-08-01 |
| ○○から分岐 | ○○より検討開始 | 検討パネルの分岐元行。木構造の用語「分岐」をユーザー向けにもそのまま使う | 2026-08-01 |
| （いま） | 現在地、選択中 | 兄弟変化ポップで表示中のラインを示す接尾辞。短く平易な語に統一 | 2026-08-01 |
| アップデートが必要です | 強制アップデート、ブロック | 「強制」「ブロック」は内部の実装用語（app_policy判定のブロック状態）。ユーザー向け画面・文言には出さない | 2026-08-05 |
| 直すべき悪手がわかる（アプリ紹介の説明文言） | 悪手を示す、悪手を教えてくれる | ユーザーが得るものを主語にする。「示す」は機械的で硬い | 2026-08-06 |
| 解析が完了しました（レポート画面の一時通知） | 解析完了 | 「解析完了」は通知タイトルで使用済み。画面内の一時表示と語感で混同しないよう別文言にする | 2026-08-07 |
| 解析中... n / m 手（レポート画面の進捗バナー・ホーム一覧の解析中カード） | 局面カウント表示（N / M 局面） | 解析対象は0手目の初期局面込みの局面数で、局面数のまま出すと手数として読んだユーザーには盤が1手遅れて見える。盤・グラフ先端と同じ(confirmedThrough-1)手基準に揃える | 2026-08-07 |
| 解析の準備中（検討パネル評価スロット・ローカルエンジン未準備／Web「棋譜を検討する」入力カードの解析開始直後） | 端末解析は準備中です、自動解析は準備中です、WASM未対応の端末です | 資産ダウンロード未完・サーバーフォールバックのどちらの原因でも成立する控えめな言い回し。「WASM」等の内部実装用語はユーザー向け文言に出さない（「棋譜を検討する」行と同じ理由）。Web版はエンジンWASMバイナリのダウンロード完了（最初の局面結果到着）まで同じ文言を表示する | 2026-08-08 / 2026-08-13 |
| 最善 ○○（検討パネル評価スロットの最善手表示） | 最善手: ○○ | 数値の直後に添える短い併記のため、コロン無しの簡潔な形にする | 2026-08-08 |
| ベータ版では1日30局まで早く解析できます。30局を超えると解析が遅くなります（同意画面） | ベータ期間中は1日30局まで解析できます | ローカルWASM解析の導入で30局は上限ではなくなった（超過分は端末内解析に切り替わり遅くなるが解析自体は可能）。実態に合わせる | 2026-08-12 |
| 初回は解析エンジンのダウンロードに時間がかかります（Web「棋譜を検討する」解析開始直後の補足） | 初回はWASMバイナリのダウンロードに時間がかかります | エンジンWASMバイナリ（約65MB）の初回ダウンロード中は「解析の準備中」表示だけだと停止に見えるための補足。「WASM」は内部実装用語のため出さない（「棋譜を検討する」行と同じ理由） | 2026-08-13 |

## 表記・スタイル

- ◎noteに「訓練で消せる」等の断定的な付記はしない（2026-07-19 #17）
- WASMの実体（ダウンロード・キャッシュされるエンジン等のファイル群）は「WASMバイナリ」と
  呼ぶ。「資産」「アセット」は使わない（コード内コメントも同様。英語識別子・URLパスの
  asset/kento-assets は既存のまま）（2026-08-09）

## 強制アップデート画面（全画面ブロック）

| 用途 | 文言 |
|---|---|
| 見出し | アップデートが必要です |
| 本文 | 最新版でのみご利用いただけます。ストアからアップデートしてください。 |
| 補足 | 棋譜と解析結果は端末に残っています。アップデート後もそのままご利用いただけます。 |
| ボタン | ストアを開く |
| バージョン表示 | お使いのバージョン 1.2.0 (42)　※数値はmono |

管理画面で `message` を設定した場合は本文の下に追記表示する。`store_url` が未設定の場合は
ボタンを出さず案内文のみにする。文言の実体は `AppStrings`（AppStrings.kt「36. 強制アップデート」節）
に一元化する。

## 引き継ぎコード表示（設定画面）

パスワードと同様の扱い。既定は伏字（マスク）表示で、コピーはマスク中でも常時可能。
生の値はユーザーの明示操作（表示切替アイコン）でのみ見せる。

| 用途 | 文言 |
|---|---|
| 表示アイコンの説明（マスク中→タップで表示） | コードを表示 |
| 表示アイコンの説明（表示中→タップで隠す） | コードを隠す |

## 引き継ぎコード入力（設定画面）

| 用途 | 文言 |
|---|---|
| 設定行 | 引き継ぎコードを入力 |
| 設定行サブ | 別の端末で発行したコードでこの端末を復元 |
| ダイアログ見出し | 引き継ぎコードを入力 |
| ダイアログ説明文 | 別の端末の設定→引き継ぎコードで表示したコードを入力してください。 |
| 入力欄ラベル | コード |
| 送信ボタン | 復元する |
| 成功メッセージ | アカウントを切り替えました |
| 成功時の閉じるボタン | 閉じる |
| 切替確認見出し（ログイン中に入力した場合） | アカウントを切り替えますか？ |
| 切替確認本文 | この端末は入力したコードのアカウントに切り替わります。今のアカウントのデータはサーバーに残り、消えません。 |
| 切替確認ボタン | 切り替える |
| エラー: コード不正（チェックサム不一致等） | コードが正しくありません。入力し直してください。 |
| エラー: サーバーに一致するコードが無い | 一致するコードが見つかりません。コードを確認してください。 |
| エラー: レート制限 | しばらく時間をおいて再度お試しください。 |
| エラー: アップデート必要 | アップデートが必要です。最新版に更新してから再度お試しください。 |
| エラー: 通信断・その他 | 通信に失敗しました。しばらくしてから再度お試しください。 |

「一致するコードが見つかりません」は、コードが存在しないのか他人のものかを区別しない
（ブルートフォースの手がかりを与えないため、サーバー側もHTTP 404を理由で出し分けない）。
文言の実体は `AppStrings`（AppStrings.kt「32. 引き継ぎコード表示・入力」節）に一元化する。
