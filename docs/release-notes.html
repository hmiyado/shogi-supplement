リリースノート — 将棋サプリ

最終更新日: 2026-08-07

1.1 — 2026-08-07

  • 評価値グラフ: レポート画面に形勢の推移グラフを追加しました。 自分視点の符号で表示し、タップやドラッグで気になる手へすぐ移動できます。 悪手の位置はグラフ上にマークされます。
  • 一致率（最善・次善）: エンジンの最善・次善手とあなたの手が 一致した割合を、悪手率と並べて表示します。
  • 検討モードの刷新: 任意の局面から指した変化を分岐として記録し、 変化どうしを切り替えながら検討できます。指した先の局面はその場で解析されます。
  • 棋譜一覧の絞り込み: 出典・先後・勝敗・期間で棋譜を絞り込めます。

1.0 — 2026-07-31

最初のリリースです。主な機能は次のとおりです。

  • 棋譜解析レポート: KIFファイル（将棋ウォーズ・lishogi等のコピーを含む）を 取り込むと、端末内の将棋エンジン（やねうら王＋Háo評価関数）が全局面を解析します。 対局ごとのレポートには、実戦の手・最善手・形勢の変化に加え、同じ棋力帯での 発生頻度を表示する悪手カードが並びます。盤面では本譜と最善の変化を再生でき、 任意の局面から先後どちらも指して検討できます。
  • 悪手ドリル: 検出した悪手を性質で分類し、あなたの棋力帯で標準的に 起きるミスだけを「今日の1問」として出題します。正解・不正解はエンジン評価で 判定されます。
  • 推定棋力（偏差値）: 実測の悪手率から強さを推定し、研究データの 対局者集団の中での相対位置を偏差値で表示します。各サービスの公式レートや 申告棋力とは独立した指標です。
  • サーバー解析: データ提供に同意すると、匿名アカウントでの 棋譜アップロードとサーバー側解析に対応します。提供は任意で、いつでも データごと削除できます。
