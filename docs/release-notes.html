リリースノート — 将棋サプリ

最終更新日: 2026-08-26

1.7 — 2026-08-26

  • 戦型・囲いの表示: 新しく解析した棋譜の戦型と囲いを、 棋譜一覧と対局情報で確認できるようになりました。
  • 戦型で絞り込み: 棋譜一覧を戦型で絞り込めるようになりました。
  • 盤面表示の調整: 次の一手とレポートの盤面サイズをそろえ、 画面全体を見やすくしました。

1.6 — 2026-08-24

  • 棋譜の個別削除: 棋譜一覧・レポート画面から棋譜を削除できるように なりました。解析結果も含めて端末から削除され、必要に応じてサーバーに保存した 棋譜も合わせて削除できます。
  • 手動棋譜入力: 棋譜ファイルがない対局も、盤上で指し手を入力して 保存・解析できるようになりました。

1.5 — 2026-08-20

  • 推定棋力の詳細ページ: ホームの推定棋力カードをタップすると、 直近の対局ごとの偏差値・悪手率・一致率や、対局サービスでの最高段級位を 確認できるようになりました。
  • 未解析棋譜の表示: 引き継ぎで復元した棋譜は保存だけ先に行い、 あとから任意のタイミングで解析を始められるようになりました。未解析の棋譜でも 盤面と棋譜操作は確認できます。

1.4 — 2026-08-17

  • アカウントを作らずに利用: はじめに、または棋譜の追加時に アカウントを作らずに始められるようになりました。解析は端末内で行い、 棋譜はサーバーに送信されません。
  • 引き継ぎコードの作り直し: 設定から新しい引き継ぎコードを 発行できるようになりました。いまのコードは使えなくなりますが、 サーバーに保存した棋譜はそのまま引き継げます。
  • 安定性の改善: 端末内解析と棋譜の引き継ぎを安定させました。

1.3 — 2026-08-15

  • 引き継ぎコードで別の端末へ移行: 設定に表示される引き継ぎコードを 新しい端末で入力すると、アカウントと棋譜を引き継げます。機種変更のときにご利用ください。
  • 安定性の改善

1.2 — 2026-08-13

  • 検討モードの端末内解析: 検討モードの解析が端末内でも動くようになりました。 初回起動時に解析エンジンを自動ダウンロードし、以降は通信のない場所でも 検討できます。回数の制限もありません。
  • 指した手をその場で自動解析: 検討モードで手を指すと、 評価値と最善手が表示されます。
  • 読み筋の折り返し表示: 検討中の変化が折り返して表示され、 長い変化も全体を見渡せます。評価値と最善手はパネル上部に表示します。
  • 引き継ぎコードの伏字表示: 引き継ぎコードは普段は伏字で表示し、 見たいときだけ表示に切り替える形にしました。伏字のままでもコピーできます。
  • 安定性の改善: 特定の条件でアプリが終了することがある問題と、 検討モードの解析が反応しないことがある問題を修正しました。

1.1 — 2026-08-07

  • 評価値グラフ: レポート画面に形勢の推移グラフを追加しました。 自分視点の符号で表示し、タップやドラッグで気になる手へすぐ移動できます。 悪手の位置はグラフ上にマークされます。
  • 一致率（最善・次善）: エンジンの最善・次善手とあなたの手が 一致した割合を、悪手率と並べて表示します。
  • 検討モードの刷新: 任意の局面から指した変化を分岐として記録し、 変化どうしを切り替えながら検討できます。指した先の局面はその場で解析されます。
  • 棋譜一覧の絞り込み: 出典・先後・勝敗・期間で棋譜を絞り込めます。

1.0 — 2026-07-31

最初のリリースです。主な機能は次のとおりです。

  • 棋譜解析レポート: KIFファイル（将棋ウォーズ・lishogi等のコピーを含む）を 取り込むと、端末内の将棋エンジン（やねうら王＋Háo評価関数）が全局面を解析します。 対局ごとのレポートには、実戦の手・最善手・形勢の変化に加え、同じ棋力帯での 発生頻度を表示する悪手カードが並びます。盤面では本譜と最善の変化を再生でき、 任意の局面から先後どちらも指して検討できます。
  • 悪手ドリル: 検出した悪手を性質で分類し、あなたの棋力帯で標準的に 起きるミスだけを「今日の1問」として出題します。正解・不正解はエンジン評価で 判定されます。
  • 推定棋力（偏差値）: 実測の悪手率から強さを推定し、研究データの 対局者集団の中での相対位置を偏差値で表示します。各サービスの公式レートや 申告棋力とは独立した指標です。
  • サーバー解析: データ提供に同意すると、匿名アカウントでの 棋譜アップロードとサーバー側解析に対応します。提供は任意で、いつでも データごと削除できます。
