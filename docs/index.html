将棋サプリ

棋譜を解析すると、あなたの棋力帯で直すべき悪手がわかります。 自分の悪手を復習して上達に繋げましょう。

棋譜を検討する

棋譜の検討はアカウント登録なし・ブラウザだけでも試せます

主な機能

棋譜解析レポート

KIFファイルを取り込むと、将棋エンジンが 全局面を解析。実戦の手・最善手・形勢の変化に加え、同じ棋力帯での発生頻度を表示する 悪手カードが並びます。

悪手ドリル

検出した悪手を性質で分類し、あなたの棋力帯で標準的に起きるミスだけを「今日の1問」として 出題します。正解・不正解はエンジン評価で判定されます。

推定棋力（偏差値）

取り込んだ棋譜の悪手率から棋力を推定し、偏差値で表示します。

棋譜を検討する

アカウント登録なしで、棋譜の解析をブラウザだけで試せます。内蔵の将棋エンジンが その場で全局面を解析し、評価値の推移と大きく損した手をグラフと一覧で確認できます。

棋譜を検討する

解析はお使いの端末内で完結します。棋譜が外部に送信されることはありません。
