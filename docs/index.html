主な機能

棋譜解析レポート

KIFファイル（将棋ウォーズ・lishogi等のコピーを含む）を取り込むと、端末内の将棋エンジンが 全局面を解析。実戦の手・最善手・形勢の変化に加え、同じ棋力帯での発生頻度を表示する 悪手カードが並びます。

悪手ドリル

検出した悪手を性質で分類し、あなたの棋力帯で標準的に起きるミスだけを「今日の1問」として 出題します。正解・不正解はエンジン評価で判定されます。

推定棋力（偏差値）

実測の悪手率から強さを推定し、研究データの対局者集団の中での相対位置を偏差値で表示。 各サービスの公式レートや申告棋力とは独立した指標です。

棋譜を検討する

アカウント登録なしで、棋譜の解析をブラウザだけで試せます。内蔵の将棋エンジンが その場で全局面を解析し、評価値の推移と大きく損した手をグラフと一覧で確認できます。

棋譜を検討する

解析はお使いの端末内で完結します。棋譜が外部に送信されることはありません。
